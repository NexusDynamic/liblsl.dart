liblsl.dart

Dart and Flutter libraries and applications for Lab Streaming Layer (LSL), networked multimodal data collection, the coordination of multiple devices in experiments, and XDF recordings.

Guides LSL Viewer web app Source on GitHub

Overview

The software in this project supports experiments that collect data on several devices, and is intended in particular for multimodal and multi-participant research. The libraries and applications run on Windows, macOS, Linux, Android and iOS, and in part in web browsers, so that a procedure developed in one laboratory can be reproduced in another with different hardware.

The LSL Viewer application displays XDF recordings and live LSL streams. The liblsl package is a Dart interface to the C++ LSL library, and xdf reads and writes XDF recordings. peer_coordinator coordinates the devices of an experiment over LSL, WebSocket or WebRTC. The transport_timing application measures latency, jitter, loss and clock drift between devices, and its results are examined in transport_timing_analysis. All libraries are published on pub.dev, and the project is MIT licensed.

Viewing recordings and streams

LSL Viewer opens XDF recordings of any size, such as those written by LabRecorder, with one tab per stream, and displays live LSL streams with filtering, re-referencing, power spectra, signal quality measures and trigger decoding. It records streams to XDF, replays recordings as LSL streams, and connects to OpenBCI Cyton boards and other serial devices. In the web app, files are read locally in the browser.

Web app · Downloads for Windows, macOS, Linux and Android · Documentation and source

A browser cannot use LSL directly. LSL streams are made available to the web app, and to other networks, through a WebSocket bridge that is started from the desktop application or with the lsl command line tool; see the bridge and relay guide.

The viewer is also available as a Flutter library, signal_viewer, with source providers for LSL streams, XDF recordings and serial devices, and its signal engine as signal_core.

Streaming and recording data

liblsl

Dart and Flutter interface to the C++ liblsl library, with full parity with the C API. It is described in a JOSS paper, and its benchmark history is published.

xdf

Reader and writer for XDF files in pure Dart, on all platforms including the web. It implements the clock synchronisation and jitter removal of pyxdf and is tested against it.

lsl_tools

Recording to XDF, the WebSocket bridge and relay, test outlets, and the lsl command line tool, which is included in the desktop releases of LSL Viewer.

Coordinating devices in an experiment

peer_coordinator

Transport-neutral coordination of devices: election of a coordinator, membership, heartbeat, data streams that are started and stopped on all devices together, and timing information on every message.

liblsl_coordinator

The LSL transport for peer_coordinator, for local networks and research hardware.

webrtc_coordinator

A peer-to-peer WebRTC transport for peer_coordinator, with a Flutter binding.

Validating timing

transport_timing

An application that measures one-way latency, jitter, loss and clock drift between devices over LSL, WebSocket and WebRTC. Downloads.

transport_timing_analysis

An application that collates and visualises the logs of a timing run from all devices. Web app.

timing_core

The record format and analysis behind both applications. The logs are XDF files.

Devices

openbci_cyton

OpenBCI Cyton and Cyton + Daisy boards over the USB dongle: commands, channel settings and samples in microvolts.

serial_transport

Serial ports on Linux, macOS and Windows, and WebSerial in browsers, through one interface.
